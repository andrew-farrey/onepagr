# List built-in template names

List built-in template names

## Usage

``` r
list_templates()
```

## Value

Character vector of built-in template names.

## Examples

``` r
list_templates()
#> [1] "cohort_summary"       "county_choropleth"    "overdose_spike_alert"
#> [4] "syndromic_alert"      "trend_snapshot"      
```
