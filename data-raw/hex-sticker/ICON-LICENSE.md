# Icon attribution

The accessibility/checkmark glyph in the `onepagr` hex sticker
(`man/figures/logo.png`) is Microsoft's Fluent System Icon
`Accessibility Checkmark 20 Regular`, recolored from its original
monochrome fill to white for use inside the green badge.

- Source icon: <https://github.com/microsoft/fluentui-system-icons/blob/main/assets/Accessibility%20Checkmark/SVG/ic_fluent_accessibility_checkmark_20_regular.svg>
- Project: <https://github.com/microsoft/fluentui-system-icons>
- License: MIT

Copyright (c) Microsoft Corporation.

The page, fold, report bars, composition, and color treatment are original to
this sticker. The palette is taken from `onepagr`'s built-in `default.typ`
theme. `microsoft-fluent-accessibility-checkmark-20-regular.svg` in this
directory is the unmodified upstream source file.
