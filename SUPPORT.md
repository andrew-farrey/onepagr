# Getting help

- **Learn how it works.** The [documentation
  site](https://andrew-farrey.github.io/onepagr/) has a getting-started
  guide, an end-to-end workflow, a theming guide, and a page on
  accessibility checks. In R, `vignette(package = "onepagr")` lists
  them.
- **Ask a question or report a bug.** Open an issue at
  <https://github.com/andrew-farrey/onepagr/issues>. A short example
  that reproduces the problem, built with
  [`example_data()`](https://andrew-farrey.github.io/onepagr/reference/example_data.md),
  is the fastest way to get an answer. Add the output of
  [`onepagr::check_quarto()`](https://andrew-farrey.github.io/onepagr/reference/check_quarto.md)
  and [`sessionInfo()`](https://rdrr.io/r/utils/sessionInfo.html).
- **Report an accessibility problem in a PDF.** Use the accessibility
  template on the same page.
- **Report a security problem.** Do not use a public issue. See
  [SECURITY.md](https://andrew-farrey.github.io/onepagr/SECURITY.md).

Please never post real, record-level, or sensitive data in an issue, in
a comment, or as an attachment.
